FAQ

Questions fréquentes

Comment réserver ?+
Choisissez votre date d'arrivée dans le calendrier, remplissez le formulaire de réservation, puis confirmez directement sur WhatsApp avec le propriétaire.
Comment payer ?+
Vous réglez un acompte par virement PayPal lors de la confirmation, puis le solde selon les modalités convenues avec le propriétaire.
Comment fonctionne le paiement par PayPal ?+
PayPal est une plateforme de paiement reconnue et sécurisée. Envoyez votre acompte via PayPal (option "à un ami/de la famille" recommandée pour éviter les frais) à luzdosol351@gmail.com, et votre réservation est confirmée dès réception.
Comment accéder à l'appartement ?+
Le propriétaire vous transmet toutes les instructions d'arrivée après confirmation de votre réservation. L'entrée est simple et autonome.
Combien de personnes peut accueillir l'appartement ?+
L'appartement est idéal pour les couples, les familles et les petits groupes d'amis. Indiquez votre nombre de voyageurs dans le formulaire.
Les animaux sont-ils autorisés ?+
Contactez directement le propriétaire via WhatsApp pour toute demande concernant les animaux.
Le ménage est-il compris ?+
Oui, le ménage de fin de séjour est inclus afin que vous profitiez pleinement de vos vacances sans souci.
Quelle est la politique d'annulation ?+
Annulation gratuite jusqu'à 30 jours avant l'arrivée (remboursement intégral de l'acompte). Entre 30 et 7 jours avant l'arrivée, 50 % de l'acompte est remboursé. À moins de 7 jours, l'acompte n'est pas remboursable. Contactez l'hôte pour toute situation particulière.
